# Tab Restore

탭이 새로고침되거나 닫혔다가 복구되어도 작성 중이던 상태를 로컬에서 다시 적용하는 Chrome 확장 프로그램입니다.

## 저장 및 복구 항목

- 일반 입력창, 선택창, 체크 상태와 커서 위치
- `contenteditable` 기반 작성 영역
- Monaco, CodeMirror 5·6, Ace 편집기 코드와 편집 위치
- 페이지 및 내부 스크롤 영역, 열린 Shadow DOM 내부 상태
- 포커스, 텍스트 선택, 미디어 재생 상태
- `details`, `dialog`, SPA의 `history.state`와 URL 해시
- 동일 출처·교차 출처 iframe별 상태
- localStorage, sessionStorage
- JSON으로 안전하게 변환할 수 있는 페이지 전역 변수

모든 항목은 토글 상태와 관계없이 계속 저장됩니다. 항목을 끄면 복구만 중단되며, 다시 켜는 즉시 저장된 값이 현재 페이지에 적용됩니다.

## 설치

1. 저장소를 내려받거나 ZIP 파일의 압축을 풉니다.
2. Chrome에서 `chrome://extensions`를 엽니다.
3. 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 선택합니다.
4. 이 폴더를 지정합니다.

로컬 `file://` 페이지에서 사용하려면 확장 프로그램 세부정보에서 **파일 URL에 대한 액세스 허용**을 켭니다.

## 단축키

- 저장 상태 복구: `Ctrl+Shift+Y`
- 현재 상태 저장 후 새로고침 및 복구: `Ctrl+Shift+U`

단축키 기능의 기본값은 꺼짐입니다. 팝업의 통합 단축키 토글을 켜야 동작합니다. 단축키의 **수정**을 누르면 Chrome 단축키 설정이 열립니다. 새 탭에서 복구 단축키를 누르면 가장 최근에 저장한 페이지를 열고 복구합니다.

## 범위와 제한

Chrome 보안 정책 때문에 비밀번호·파일 입력, 닫힌 Shadow DOM, 페이지 클로저 안의 지역 변수, 직렬화할 수 없는 네이티브 객체는 복구하지 않습니다. Chrome 내부 페이지와 Chrome 웹 스토어 페이지에는 콘텐츠 스크립트를 삽입할 수 없습니다. 자동 재생이 차단된 사이트에서는 미디어 위치는 복구되지만 재생은 사용자 입력 전까지 보류될 수 있습니다.

저장 데이터는 확장 프로그램의 IndexedDB에만 보관되며 외부 서버로 전송하지 않습니다. 최근 상태는 최대 200개까지 유지됩니다.
